# 🎬 Hacks Stream

An AI-powered video recommendation engine that helps you discover content about Faith, Technology, and African Innovation.

## ✨ Features

- 🔍 Search and discover videos from YouTube
- 🧠 AI-powered recommendations that learn from your preferences
- 🌙 Time-aware boosting (Tech by day, Faith by night)
- 🎨 Customizable themes (Dark, Light, Afro)
- 📌 Save videos to Watch Later
- 🔗 Share videos with friends
- 📈 Track your engagement analytics
- 📥 Export your watch history

## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher
